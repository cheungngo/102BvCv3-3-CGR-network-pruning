0. METHODS OVERVIEW
----------------------------------------------------------------------------------------------------
This pipeline queries ChEMBL (bioactivity + curated mechanisms), Open Targets (genetic
association weights) and STRING (human PPI, score cutoff below) live, then runs an
affinity-weighted leave-one-out (LOO) ablation of the CGR stack across MDD, BIP, SCZ and
OCD. Component importance = mean 'unique_delta' = drop in disorder-weighted module
coverage when a component is removed. Coverage uses network proximity from each disorder
anchor to the nearest drug target, scaled by target affinity:

    eff_distance = shortest_path(anchor, target) / max(1, pChEMBL - 4.5)
    coverage     = Σ_anchor [ disorder_score · 1/(1+min_eff_distance) ] / Σ_anchor disorder_score

Three sensitivity modes are reported:
  • binding_only            : ChEMBL pChEMBL >= cutoff targets only.
  • with_metabolic          : adds curated mechanistic/metabolic/structural targets.
  • with_metabolic_and_pk   : as above, PLUS a CYP2D6 PK gate — dropping the CYP2D6
                              inhibitor attenuates DXM target potency by PK_DXM_PENALTY,
                              quantifying the inhibitor's true functional indispensability.

9. CAVEATS
----------------------------------------------------------------------------------------------------
  • Curated mechanistic pChEMBL values are modelling assumptions, not measured affinities;
    see Section 5 for their effect on ranks.
  • STRING proximity is a static, undirected structural proxy; the PK mode (Section 4) is a
    first-order correction for one known PK interaction (CYP2D6) only.
  • Open Targets scores aggregate heterogeneous evidence; absolute magnitudes are relative.
  • FDA 'replacement' candidates are network/affinity hypotheses, NOT clinical recommendations.
